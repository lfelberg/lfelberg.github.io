# BakePrice — Next Features

This document captures potential features for future BakePrice improvements. The order below is not a final priority ranking.

## Requested ideas

1. **Teams** — Allow users to invite team members and share recipes, ingredient costs, orders, and other bakery information.
2. **Recipe imports** — Let users import existing recipes from files or other common formats instead of entering everything manually.
3. **Recipe photos** — Let users attach photos to recipes for easier recognition, organization, and sharing.
4. **Ratings pop-up** — Add a friendly, well-timed prompt that asks satisfied users to rate BakePrice.
5. **Recipe-specific labor rates** — Allow users to set a different hourly labor rate for individual recipes when specialized or detailed work needs different pricing.
6. **Waste and scrap allowance** — Add a configurable waste percentage to recipes so spills, trimming, testing, and unusable ingredients are reflected in the true cost.

## Additional ideas

7. **Ingredient price alerts** — Notify users when ingredient prices change and show which recipe costs or margins are affected.
8. **Batch scaling and unit conversions** — Scale recipes to a target yield and automatically convert weights, volumes, and temperatures.
9. **Inventory and low-stock reminders** — Track ingredient quantities and alert users when supplies or packaging need to be reordered.
10. **Order calendar** — Combine orders, preparation dates, pickup times, and payment deadlines in a single bakery schedule.
11. **Profitability reports** — Compare bestsellers, margins, and cost trends so users can identify the most profitable products.

## Future planning notes

- Define the smallest useful version of each feature before implementation.
- Validate priority with user feedback and support requests.
- Review privacy and permission requirements before building Teams or shared data.
- Decide which import formats should be supported before designing recipe imports.
